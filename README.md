# Level 2031
A mobile-first PWA prototype for the Level 2031 life RPG.

## Run
Serve this folder from HTTPS (or localhost) and add it to the iPhone Home Screen from Safari.

## Current MVP
- RPG-style home/world screen
- XP and level system
- Time-based daily mission tiers
- Core missions and completion XP
- Universal streak display
- Lifetime stats dashboard
- Life Log
- Dark/light mode
- Local-first storage
- PWA manifest + service worker

This is the first playable foundation. Detailed modules can be layered onto the same data model.
